# Agriculture 2026 · 유구천 유역 지하수 모니터링

2025년 월말 지하수위 자료를 지도와 그래프로 비교하는 웹 시작품입니다. 약 50m 원본 격자 113,076개를 표시하고, 월별 수위 변화·등수두선·수위 저하 지표를 조회하며 GIS/CAD 파일을 내보낼 수 있습니다.

현재 정식 버전은 **v1.0.0**입니다. `package.json`, `package-lock.json`, `VERSION`을 같은 버전으로 관리하고, 배포 기준은 Git 태그 `v1.0.0`으로 식별합니다. 변경 이력은 [CHANGELOG.md](CHANGELOG.md)를 참고합니다.

시연은 본 진행 18분과 여유 2분으로 구성했습니다. 시간은 권장 배정이며 실제 음성 발표 시간을 실측한 결과가 아닙니다.

산정 방식은 MODFLOW 6 계산 결과입니다. 수위 저하 단계와 변동 경보는 참고 기준이며 공식 가뭄 판정이나 실시간 운영 경보가 아닙니다.

## 주요 기능

- 지도 표시: 연평균 대비 편차, 전월 대비 변화량, 수위 표고, 연간 변동 폭.
- 시점 선택: 2025년 1~12월, 계절별 빠른 선택, 월별 재생, 12개월 비교.
- 연간 변동 폭 선택 시 월 선택·계절 필터·재생 비활성화.
- 약 50m 네모 격자 또는 원형 Point 표시, 격자선·투명도 조절.
- 유역 전체 영역 맞춤: 원본 격자의 실제 범위와 지도 화면 크기에 맞춰 자동 확대하며, 지도 위 버튼·하단 안내·모바일 패널을 고려합니다. 직접 이동·확대한 위치는 화면 크기가 바뀌어도 유지하고, 맞춤 버튼으로 자동 맞춤을 다시 켭니다.
- 월별 지하수위 등수두선: 수위 표고 모드에서 5m/10m 간격으로 표시.
- 수위 저하 지표, 예시 관리구역·관측정 보조 레이어.
- 격자 선택 시 월별 수위 그래프와 상세 지표 조회, 선택 해제.
- 월말 수위의 전월 대비 상승·하강 경보 목록과 기준 설명.
- SHP ZIP, GeoJSON, DXF 내보내기.
- 데스크톱·태블릿·모바일에 대응하는 반응형 화면.

## 빠른 시작

Git, Node.js 22 이상과 npm이 필요합니다. `.nvmrc`와 GitHub Actions는 Node.js 22를 사용합니다. 저장소에는 실행에 필요한 수위 자료와 월별 등수두선이 포함됩니다.

```sh
git clone https://github.com/voldoda/Agriculture_2026.git
cd Agriculture_2026
git checkout v1.0.0
npm ci
```

주요 데이터 파일은 약 120MB입니다. 저장소에는 이를 약 30MB의 **분할 gzip 파일**로 압축해 포함합니다. `npm ci`의 설치 완료 단계에서 `src/data/groundwater_data.json`을 자동 복원하고, SHA-256과 파일 크기로 원본과 바이트 단위 일치를 검증합니다. Git LFS는 필요하지 않습니다. ZIP을 내려받은 경우에도 압축을 풀고 `npm ci`를 실행하면 됩니다.

설치 스크립트를 생략했거나 데이터를 다시 복원하려면 `npm run prepare:data`를 실행합니다. 압축 자료의 무결성만 확인하려면 `npm run prepare:data -- --verify`를 사용합니다. 기존 파일이 원본과 정확히 일치하면 다시 쓰지 않습니다.

필요하면 `.env.example`을 `.env`로 복사해 Vworld 지도 키를 입력합니다.

```dotenv
VITE_VWORLD_KEY=발급받은_Vworld_지도_키
```

- 키가 없어도 OpenStreetMap 배경으로 격자 조회·분석 기능을 사용할 수 있습니다.
- Vworld 일반·위성·다크 지도는 키를 설정했을 때 제공됩니다.
- `.env`는 Git에서 제외합니다. 설정 변경 후에는 개발 서버를 재시작합니다.
- `VITE_` 변수는 브라우저용 빌드에 포함되므로 서버 비밀키를 넣지 않습니다. Vworld 키에는 실제 사용 주소에 맞는 제한을 설정합니다.

```sh
npm run dev
```

브라우저에서 <http://localhost:8080/>에 접속합니다. 현재 개발 설정은 네트워크 인터페이스에도 바인딩하므로, 같은 네트워크에서는 서버 PC의 내부 IP와 8080 포트로 접속할 수 있습니다. 처음 실행할 때 대용량 데이터 로딩 시간이 필요합니다.

## 배포 전 로컬 확인

다음 명령으로 실제 배포할 빌드를 만들고, 이 PC에서만 접근하는 미리보기 서버를 실행합니다.

```sh
npm run build
npm run preview -- --host 127.0.0.1 --port 4173 --strictPort
```

브라우저에서 <http://127.0.0.1:4173/>에 접속합니다. 소스를 수정한 뒤에는 다시 빌드하고 페이지를 새로고침해야 최신 결과를 볼 수 있습니다. 미리보기 실행만으로 운영 사이트에 배포되지는 않습니다.

- 유역 전체 영역 맞춤, 창 크기 및 분석 패널 너비 변경, 직접 이동·확대한 위치 유지를 확인합니다.
- 월·지도 항목 변경, 레이어 표시, 지점 선택, 그래프 및 내보내기 동작을 확인합니다.
- 작은 화면에서 지도와 하단 분석 패널이 겹치지 않는지 확인합니다.

## 데이터와 계산 기준

### 수위와 격자

- 2025년 1~12월 월말 지하수위이며, 산정 방식은 **MODFLOW 6 계산 결과**입니다.
- 화면의 월 선택은 `1월`~`12월`로 표시합니다. 연도·월 아래에 자료 기준과 산정 방식을 항상 안내하고, 별도로 생성한 자료의 `(예시값)` 표시는 유지합니다. 그래프에서 제공 자료의 월 이름에는 별도 괄호를 붙이지 않습니다.
- 원본 수위는 float64로 계산하며, DBF의 십진 문자열을 `headsExact`에 별도 보존합니다. 화면의 반올림 표시는 계산 정밀도와 구분합니다.
- 원본 유효 격자 113,076개를 사용합니다. 간격은 가로 약 49.9757m, 세로 약 49.9768m입니다.
- 기본 투영 좌표계는 EPSG:5179이며, 웹 지도는 경위도 좌표를 사용합니다.
- 결측값은 다른 월이나 임의 값으로 대체하지 않습니다.

| 지도 항목 | 계산 기준 | 단위 |
| --- | --- | --- |
| 연평균 대비 편차 | 선택 월 수위 − 같은 격자의 12개 월말 수위 산술평균 | cm |
| 전월 대비 변화량 | 선택 월말 수위 − 직전 월말 수위 | cm |
| 수위 표고 | 선택 월 원본 수위 | m |
| 연간 변동 폭 | 같은 격자의 1~12월 최고수위 − 최저수위 | cm |

12개월 산술평균은 장기 평년값이나 시간가중 연평균이 아닙니다. 전년도 12월 자료가 없어 1월의 전월 비교는 불가합니다. 평균과 연간 변동 폭은 12개월 중 하나라도 결측이면 계산하지 않습니다.

### 등수두선과 지표고

- 등수두선은 원본 셀 중심 수위에서 Marching Squares로 생성합니다. 선형 보간을 사용하고, 결측 또는 유효 중심점 영역 밖으로 외삽하지 않습니다.
- 월별 GeoJSON과 manifest는 `public/contours/`에 저장하며 수위 자료와 출처 해시·연도·월을 대조합니다.
- 지표고는 SRTMGL1 약 30m DEM의 격자 중심 보간 참고값입니다. 취득 시기는 2000년이며 수직 기준은 EGM96입니다.
- 표고−수두 차이는 부호를 보존하는 참고값입니다. 모형의 높이 기준과 수면 해석이 확인되기 전 확정 지하수심은 산정하지 않습니다.
- 지질 분류, 관리구역, 관측정은 예시이며 실시간 관측 연동은 없습니다. 검증되지 않은 고정 유동 화살표는 제공하지 않습니다.

### 수위 저하 단계와 변동 경보

수위 저하 지수는 다음과 같습니다.

```text
(연내 최고수위 − 선택 월 수위) / max(5m, 연간 변동 폭)
```

35% / 55% / 75% 경계로 저하 작음·보통·큼·매우 큼을 표시합니다. 지표고는 이 단계 점수에 포함하지 않습니다. 지하수 가뭄 공식 기준이 아닙니다.

변동 경보는 전월 대비 수위 변화의 절댓값으로 구분합니다.

| 참고 단계 | 변화량 절댓값 |
| --- | --- |
| 관심 | 0.25m 이상, 0.50m 미만 |
| 주의 | 0.50m 이상, 1.00m 미만 |
| 중점 검토 | 1.00m 이상 |

상승·하강 방향을 함께 표시합니다. 1월은 비교할 이전 자료가 없어 경보를 산정하지 않습니다. 저류량·저류율은 대수층 매개변수가 부족해 산정하지 않습니다.

## 내보내기

- **SHP ZIP:** Point/Polygon 격자, EPSG:5179·5186·4326 선택. PRJ와 실제 좌표를 일치시키며 분석 출처를 `metadata.json`에 기록합니다.
- **GeoJSON:** RFC 7946의 경도·위도 순서. 선택 월 등수두선과 보조 레이어를 포함할 수 있습니다.
- **DXF:** 선택 월의 격자·수위 텍스트·등수두선 및 보조 레이어. 선택한 투영 좌표계를 사용합니다.
- 화면과 같은 계산 함수·월을 사용합니다. 결측 숫자는 SHP 공백, GeoJSON `null` 등 형식에 맞게 보존합니다.
- 파일 생성과 다운로드는 브라우저에서 수행합니다.

## 원자료 갱신

실행용 데이터는 저장소에 포함되어 있으므로, 일반 실행에는 원본 SHP나 DEM을 별도로 준비할 필요가 없습니다. 재생성할 때만 원본을 준비합니다.

### 2025년 수위 자료

원본 `Heads_2025_Monthly_5179.shp/.shx/.dbf/.prj/.cpg`를 `source-data/heads2025/`에 넣거나 `GROUNDWATER_SOURCE_DIR` 환경변수로 원본 폴더를 지정합니다.

```powershell
$env:GROUNDWATER_SOURCE_DIR = '원본_SHP가_있는_폴더'
node scripts/import-2025.mjs
npm run generate:contours
node scripts/validate-source.mjs
node scripts/package-data.mjs
npm run prepare:data -- --verify
npm test
```

수위 재입력 후에는 등수두선을 반드시 다시 생성합니다. 원본 파일 자체는 변경하지 않습니다. 새 수위 자료를 다른 환경에 배포하려면 복원용 데이터 묶음도 `node scripts/package-data.mjs`로 갱신합니다. 갱신 전 로컬 자료를 백업하고, 이후 `npm run prepare:data -- --verify`로 확인합니다. manifest와 다른 로컬 JSON은 자동으로 덮어쓰지 않고 오류를 알립니다. 로컬 자료 수정만으로는 배포 자료가 바뀌지 않습니다.

### SRTM 지표고

DEM 원본 ZIP은 `source-data/srtm30/`에 준비합니다. 필요한 타일을 다운로드하면서 반영하려면 다음 명령을 사용합니다.

```sh
npm run import:surface -- --download
npm test
```

DEM 반영 스크립트는 기존 수위·원본 좌표를 유지하고 지표고 참고값만 갱신합니다. 원본 대조, DEM 표본 비교와 물리적 타당성 검증은 구분해야 합니다.

`process_sample_data.py`는 과거 예시 자료 생성용입니다. 현재 2025년 데이터 갱신에는 사용하지 않습니다. 과거 검토 스크립트는 작성 당시 자료 해시와 원본·표본 파일을 요구할 수 있습니다.

## 배포와 현재 한계

`npm run build`로 생성한 `dist/`를 HTTPS 웹 서버 또는 정적 호스팅에 배포합니다. `vite preview`는 로컬 확인용입니다. 외부 주소에서 Vworld 키 허용 설정과 지도 로딩을 확인해야 하며 현재 위치 기능은 HTTPS가 필요합니다.

주요 JSON 파일이 약 120MB이므로 호스팅의 단일 파일 제한·전송량과 초기 로딩 시간을 확인해야 합니다. 압축·캐시 또는 대용량 저장소를 적용하고, 더 큰 데이터나 다수 사용자 운영에는 영역별 데이터 조회 구조를 검토할 수 있습니다.

로그인, 사용자 권한, 서버 DB, 자료 업로드 API, 실시간 관측 연동, 외부 전송 기능은 현재 구현 범위에 포함되지 않습니다.

## 자료 이용과 권리

본 저장소에 별도 오픈소스 라이선스를 부여하지 않았습니다. 프로그램·모형 결과·기관 로고 등 자료의 재사용·외부 배포는 권리자의 허용 범위를 확인합니다. Vworld·OpenStreetMap·SRTM 등 외부 자료는 해당 서비스의 이용 조건과 출처 표기 기준을 따릅니다.

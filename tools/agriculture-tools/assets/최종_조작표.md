# 입력 기준과 복구 요령

## 발표 전 확인

npm ci → npm test → npm run build → npm run preview -- --host 127.0.0.1 --port 4173 --strictPort. 접속 주소는 http://127.0.0.1:4173/입니다. 데이터 로딩과 지도 표시 완료 뒤 시작합니다. Vworld 키가 없으면 OpenStreetMap 일반 지도가 정상입니다.

## 설명할 계산 기준

| 항목 | 발표 시 설명 |
| --- | --- |
| 수위 자료 | 2025년 1~12월 월말 수위 / MODFLOW 6 계산 결과. |
| 편차·변화량 | 편차: 동일 격자의 12개월 월말 평균 대비. 변화량: 직전 월 대비. 단위 cm. |
| 연간 변동 폭 | 연내 최고-최저 수위. 월·재생·계절별 퀵 필터 비활성화. |
| 등수두선 | 같은 월 수위 표고를 연결. 수위 표고 모드에서만 표시. |
| 수위 저하 지수 | (연내 최고-선택 월) / max(5m, 연간 변동 폭). 35·55·75% 경계의 예시 단계. |
| 참고 경보 | 전월 변화 절댓값 25~<50cm 관심, 50~<100cm 주의, 100cm 이상 중점 검토. |
| 해석 제한 | 예시 지수는 공식 가뭄 판정 아님. DEM 차이는 확정 지하수심 아님. 저류량은 산정 자료 없음. |

## 빠른 복구

지도가 멀어졌다면 유역 전체 영역 맞춤. 월이 잠겨 있으면 원본 격자의 지도 표시를 연간 변동 폭에서 수위 표고로 변경. 등수두선이 잠겨 있으면 수위 표고로 변경. 저하 격자만 볼 때는 수위 표고에서 저하 레이어를 켜고 원본 격자를 끕니다.

선택 해제는 오른쪽 선택 해제, 지도 선택 표시 닫기 또는 Esc. 대화상자가 열려 있으면 Esc는 대화상자를 먼저 닫습니다. 1월 경보 없음은 전년도 12월 자료 부재에 따른 정상 예외입니다.

## 파일 저장과 지연 대응

출력 전에 재생을 멈추고 5월을 확인합니다. SHP는 중심점·EPSG:5179·현재 월로 한 건 저장합니다. 전체 유효 격자가 대상이며 선택 지점만 출력하는 기능은 아닙니다. 저장된 ZIP의 shp·shx·dbf·prj·cpg·metadata.json을 확인합니다.

GeoJSON은 EPSG:4326 고정, DXF는 현재 월 고정입니다. 파일 생성 중 반복 클릭하지 않고 브라우저의 실제 저장 완료를 확인합니다. 30초 이상 지연되면 설명을 줄이고, 해결되지 않으면 미완료 상태를 밝힙니다. 19:30부터 요약해 20:00 안에 마칩니다.

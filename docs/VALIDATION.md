## 실제 화면에서 확인한 내용

- 초기 5월 지도, 월말 수위 자료 기준, 키 미설정 시 OpenStreetMap 배경 표시.
- 연간 변동 폭 선택 시 월 선택·재생·계절별 퀵 필터 비활성화와 월별 항목 복귀 시 제어 복원.
- 수위 표고에서 5m 등수두선과 해당 월·표시 간격 안내.
- 5월 경보 YG-R504_C279 선택, 지도·상세 정보 연동과 선택 해제.
- 1월 전월 경보에 전년도 12월 자료 없음 안내.
- 12개월 비교 화면의 월별 카드 12개와 닫기.
- 예시 수위 저하 격자의 단독 전체 표시 안내, 일반 수위 지도 복귀.
- 현재 5월 SHP 중심점·EPSG:5179 다운로드. 실제 저장된 ZIP의 CRC, shp·shx·dbf·prj·cpg·metadata.json 구성을 확인.

모든 포맷의 외부 GIS·CAD 재개방, 실제 모바일 기기, 운영 서버·권한·성능·보안 검수와 사람의 전체 음성 발표 실측은 이 기록에 포함하지 않습니다. 전체 발표 시간은 시연 문서의 권장 배정과 구분합니다.

## 유지한 안내

Recharts 2의 지원 종료 안내와 Vite의 500kB 초과 청크 경고가 있습니다. 기능 기준을 유지하여 주 버전 업그레이드를 수행하지 않았습니다. 이번 등록에서 의존성 취약점 감사를 새로 수행하지 않았으며 설치·테스트·빌드 성공이 운영 보안 검수를 의미하지는 않습니다.

- 웹 자동 테스트 64개, 배포 빌드 통과. 포커스·가시 영역 회귀 테스트 5개를 추가했습니다.
- 내보내기 창의 초기 포커스, Tab·Shift+Tab 순환, 배경 inert, Esc 닫기 및 실행 버튼으로 포커스 복원을 브라우저에서 확인했습니다. 배경 재생에 접근해 대상 월이 바뀌던 경로를 차단했습니다.
- 390px·320px 화면의 최소·절반·확대 패널에서 지도 영역과 패널을 분리하고 선택 배지·지도 설명이 가려지지 않음을 확인했습니다. 확대 패널은 지도·배지 공간을 남기는 높이 제한을 사용합니다.
- 관리구역 3개에 실제 SVG 빗금을 적용하고 범례와 일치함을 확인했습니다.
- 운영 주소 `https://agriculture.wesmart.synology.me`에서 기존 운영 키의 일반·위성/하이브리드·다크 타일 로딩과 실제 지도를 확인했습니다. 이 확인은 운영 키 검수이며 새 수정본을 운영 서버에 배포했다는 뜻은 아닙니다. 키는 저장소와 검수 문서에 기록하지 않습니다.
- QGIS 3.30.1 엔진에서 실제 내려받은 SHP 중심점·격자 다각형 각각 113,076개, EPSG:5179·5186 자동 인식, 빈 형상 0개를 확인했습니다. EPSG:5186 PRJ에 식별 정보를 추가해 사용자 정의 좌표계로 인식되던 문제를 보완했습니다.
- GeoJSON은 WGS84의 격자·관측정 Point 113,081개, 관리구역 Polygon 3개와 등수두선 LineString 15개로 재개방했습니다. QGIS에서 겹쳐 렌더링했습니다.
- 실제 DXF를 QGIS 및 AutoCAD 2026 Core Console에서 재개방했습니다. AutoCAD 정상 종료와 격자 객체 565,380개, 수위 텍스트 56,538개, 등수두선 7,275개, 관리구역 객체 20개, 관측정 객체 10개를 확인했습니다. 이번 파일은 8월·10m 등수두선 기준입니다. DXF를 GIS에서 사용할 때 EPSG:5179를 별도로 지정합니다.
- Android 실기기·실제 GPS는 사용자 요청에 따라 2026-11-09에 후속 검수합니다. 브라우저 크기 검증을 실기기 검수로 간주하지 않습니다. 보안·부하·다른 운영체제 및 모든 외부 프로그램 버전을 포괄한 인증은 아닙니다.
